# 🍎 Калории — локальный трекер питания для iPhone

PWA-приложение: устанавливается на iPhone прямо из Safari, **без App Store, без аккаунтов, без подписок**. Все данные и нейросеть — только на твоём устройстве.

## Что внутри

| Возможность | Как работает |
|---|---|
| 📸 Распознавание еды по фото | Нейросеть MobileNetV2 (TensorFlow.js) встроена в приложение (~13 МБ) и считает прямо на телефоне, офлайн |
| 🔍 Ручной поиск | База из 345 продуктов и блюд на русском с БЖУ на 100 г, поиск с опечатками и ё/е |
| 🧠 Советник | Локальный «ИИ-советник»: считает твою норму (Mifflin–St Jeor), анализирует день и неделю, даёт конкретные рекомендации и подбирает, что съесть под оставшиеся калории/белки |
| 🤖 ИИ-чат | Настоящая языковая модель **Qwen 2.5** прямо на телефоне: отвечает на вопросы о питании, видит твой дневник, цели и вес. Скачивается один раз (~460 МБ), дальше работает офлайн |
| ⚖️ График веса | Журнал веса с графиком за месяц, трендом и дельтой за 30 дней |
| 📝 Заметки | К каждой записи еды можно добавить заметку («домашний рецепт», «без масла»…) |
| 💧 Вода, БЖУ, статистика | Кольцо калорий, бары белков/жиров/углеводов, вода, график недели, серия дней |
| 💾 Данные | Экспорт/импорт в JSON, всё в localStorage устройства — на сервер ничего не уходит |

## Установка на iPhone (2–3 минуты)

### Способ 1. Netlify Drop (самый простой, без регистрации)

1. Распакуй `kalorii.zip`.
2. Открой в браузере (с компьютера или с телефона): **https://app.netlify.com/drop**
3. Перетащи папку `kalorii` (всю целиком, с файлами внутри) в окно.
4. Через пару секунд получишь ссылку вида `https://что-то-там.netlify.app`.
5. Открой эту ссылку **на iPhone в Safari**.
6. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой"»** → «Добавить».
7. Готово! На рабочем столе появится иконка «Калории». Открывай как обычное приложение — полный экран, офлайн.

### Способ 2. GitHub Pages

1. Создай на GitHub новый публичный репозиторий.
2. Загрузи содержимое папки `kalorii` (не папку, а файлы внутри) в корень репозитория.
3. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
4. Через минуту приложение будет доступно по адресу `https://твой-ник.github.io/имя-репозитория/`.
5. Дальше шаги 5–7 из первого способа.

#### Через git (если репозиторий уже есть)

В проекте уже лежит готовый workflow `.github/workflows/pages.yml` — GitHub сам соберёт и опубликует сайт после push (Settings → Pages → Source: **GitHub Actions**). Нужно только:

```bash
cd kalorii
git remote add origin https://github.com/ТВОЙ-НИК/ТВОЙ-РЕПО.git
git push -u origin main
```

Через 1–2 минуты сайт появится на `https://ТВОЙ-НИК.github.io/ТВОЙ-РЕПО/`.

> ⚠️ PWA требует HTTPS — поэтому просто открыть файл с диска не получится. Netlify/GitHub Pages дают бесплатный HTTPS автоматически.

## Первый запуск

- При первом открытии нужно подключение к интернету, чтобы загрузить само приложение (~15 МБ — включает модель распознавания еды).
- После этого приложение работает **полностью офлайн**: записи, советы и распознавание по фото.
- **ИИ-чат** при первом использовании дополнительно скачает языковую модель (~460 МБ, один раз). Для быстрой работы рекомендуется iPhone 13+ и iOS 18 (WebGPU); на более старых устройствах модель работает медленнее (на CPU).
- Приложение попросит доступ к камере при первом фото.

## Советы по точности распознавания

- Снимай одно блюдо крупным планом, при хорошем свете, тарелку — сверху.
- Нейросеть хорошо знает типичную еду: пицца, бургеры, фрукты, овощи, супы, салаты, десерты. Сложные домашние блюда («бабушкин пирог») распознаёт хуже — для них есть ручной поиск.
- Если результат неверный — просто выбери правильное из поиска, это займёт 5 секунд.

## Ограничения (честно)

- Пищевая ценность в базе — усреднённые справочные значения, реальные блюда могут отличаться.
- Советник — это экспертные правила на основе твоих данных, не медицинская рекомендация. При проблемах со здоровьем консультируйся с врачом.
- Вес записывается вручную — приложение не взвешивает еду (это умеют только платные сервисы с огромными базами).

## Обновление приложения

Залей новую версию тем же способом (перетащи папку в Netlify Drop снова — ссылка обновится, либо перезапиши файлы в репозитории). Service worker сам подтянет новую версию при следующем открытии приложения (обычно в течение минуты). Данные на телефоне при этом сохранятся.

## Технические детали

- **Стек:** чистый HTML/CSS/JS, без сборки и фреймворков.
- **ИИ:** TensorFlow.js 4.22 + MobileNetV2 (ImageNet-классы еды замаплены на базу продуктов).
- **Офлайн:** Service Worker кэширует всё приложение, включая веса нейросети.
- **Советник:** Mifflin–St Jeor, цели похудение/поддержание/набор, ~30 правил анализа дня и недели.
- **Разработка:** в папке `tools/` — юнит-тесты движка (`test.mjs`), smoke-тест UI на jsdom (`smoke-ui.mjs`), генератор иконок.

## Приватность

100% данных на устройстве: нет серверов, нет аналитики, нет трекеров. Фото обрабатываются локально и никуда не отправляются.
